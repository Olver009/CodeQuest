# CodeQuest 🚀

Локальная десктопная платформа для изучения языков программирования (Python, Java, C++, C, JavaScript, HTML, CSS). 
Проект создан как бесплатная альтернатива онлайн-школам: без подписок, без воды, полностью офлайн.

Работает без интернета: все библиотеки интерфейса и портативные среды разработки лежат внутри приложения, никаких CDN-запросов.

## 🚀 Возможности

*   **8 курсов в одном приложении:** Python, Java, C++, C, JavaScript, HTML, CSS и вводный курс «Понимание кода».
*   **Интерактивная карта уроков:** Визуальный путь с главами, контрольными точками и трофеями. Прогресс по каждому языку сохраняется отдельно.
*   **Встроенный редактор кода:** Подсветка синтаксиса (CodeMirror) под каждый язык, автодополнение, автозакрытие скобок и кавычек.
*   **Реальный запуск кода:** 
    *   Python, Java, C, C++, JavaScript компилируются и запускаются прямо в приложении через встроенный терминал (xterm.js).
    *   Для HTML и CSS работает живой предпросмотр в мини-браузере: меняешь код — сразу видишь результат.
*   **Прогресс и геймификация:** Система сохранения прогресса, ежедневная серия (streak) с механизмом заморозки, уникальные достижения для каждого языка, общие ачивки (полиглот, серии дней).
*   **Гибкая настройка:** 
    *   Два языка интерфейса: русский и английский.
    *   Светлая и тёмная темы приложения.
    *   Три темы для редактора кода (Material, Dracula, Monokai).
    *   Масштабируемый шрифт и безрамочное окно с собственными кнопками управления.
*   **Экспорт и импорт:** Возможность сохранить весь прогресс в один файл и перенести на другой компьютер.
*   **Режим «книга»:** Отдельный экран для чтения длинной теории с тёмной темой и подсветкой кода.

## 🛠 Технологии

*   **Python 3.10+** (логика приложения, управление окном, компиляция и проверка кода).
*   **PyWebView** (создание нативного окна Windows с использованием WebView2).
*   **pywinpty** (псевдотерминал для интерактивного запуска кода с `input()`).
*   **HTML / CSS / JavaScript** (интерфейс).
*   **CodeMirror** (редактор кода), **marked** + **highlight.js** (теория), **xterm.js** (терминал) — всё локально, в `web/vendor/`.
*   **JSON** (хранение базы уроков и прогресса).
*   **Портативные среды (`runtime/`):** 
    *   `python` (для Python)
    *   `java` (JDK для Java)
    *   `mingw64` (gcc/g++ для C и C++)
    *   `nodejs` (для JavaScript)
    *   Позволяют запускать код ученика без необходимости устанавливать эти языки на компьютер.
*   **PyInstaller** (сборка `.exe`), **Inno Setup** (установщик).

## 📦 Как запустить

**Вариант 1: Готовый установщик (не требует установки языков)**
1. Скачайте `CodeQuest-Setup-<версия>.exe` из раздела **Releases**.
2. Запустите двойным кликом, выберите папку установки (по умолчанию `%LOCALAPPDATA%\Programs\CodeQuest`).
3. После установки — ярлык «CodeQuest» в меню Пуск и на рабочем столе. Внутри уже лежат все портативные среды, поэтому ничего дополнительно устанавливать не нужно.
4. Нужен только **WebView2** — во Windows 10/11 он обычно уже есть. Если его нет, установщик сам откроет страницу загрузки [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

> Есть и портативный вариант: `CodeQuest-<версия>-portable.zip` — распакуйте в любую папку и запустите `CodeQuest\CodeQuest.exe`.

**Вариант 2: Запуск из исходников (для разработки)**
1. Установите Python 3.10+ на компьютер.
2. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите `start.bat` (или `pythonw main.py`).

> В архив исходников намеренно не входит папка `runtime/` — это бинарники портативных сред (Python, Java, MinGW, Node.js), они весят сотни мегабайт и не хранятся в git. Без неё приложение сможет запускать только код на Python (если он установлен в системе). Для полноценной работы скачайте готовый установщик или портативную версию из **Releases**.

## ⚠️ SmartScreen при первом запуске

При первом запуске `CodeQuest-Setup-<версия>.exe` Windows может показать синее окно:

> **Windows защитила ваш компьютер**  
> Приложение может быть небезопасным.

Это **не вирус**. Так Windows реагирует на любой `.exe`, у которого нет платной цифровой подписи (сертификат стоит от $200 в год). Подпись подтверждает личность издателя, но не гарантирует безопасность кода. У CodeQuest её нет, потому что проект некоммерческий.

**Как запустить:**
1. Нажми **«Подробнее»** (или *More info*).
2. Нажми **«Выполнить в любом случае»** (или *Run anyway*).

Если не доверяешь скачанному файлу — можешь собрать проект из исходников сам: `python build.py` (инструкция ниже). Код открыт, любой может проверить, что внутри. 

## 🔨 Сборка exe и установщика

Одним скриптом (он же читает версию из `version.ini`):

```bash
pip install -r requirements.txt
pip install pyinstaller                    # нужен только для сборки
winget install JRSoftware.InnoSetup        # нужен только для установщика
python build.py
```

Готовые файлы появятся в `release/`: установщик, portable-архив и архив исходников.

Пошагово, если нужно собрать что-то одно:

```bash
python -m PyInstaller CodeQuest.spec       # -> dist\CodeQuest\CodeQuest.exe
ISCC.exe installer.iss /DAppVersion=1.0.0  # -> release\CodeQuest-Setup-1.0.0.exe
```

## 📁 Структура проекта

```
main.py                 — бэкенд: окно, компиляция и запуск кода, прогресс, достижения
web/                    — интерфейс (HTML/CSS/JS) и локальные библиотеки в web/vendor/
lessons/<lang>/<ui>/    — roadmap.json (карта), <lang>_db.json (уроки), trophies.json (КР) для каждого языка
runtime/                — портативные среды (Python, Java, MinGW, Node.js) для запуска кода ученика
installer.iss           — скрипт установщика Inno Setup
CodeQuest.spec          — конфигурация сборки PyInstaller
build.py                — сборка всего релиза одной командой
version.ini             — версия приложения (единственное место, где её менять)
start.bat               — запуск из исходников
release/                — готовые артефакты (не хранится в git)
```

## 💾 Где хранятся данные

Прогресс пишется в `progress.json` рядом с `CodeQuest.exe` (в исходниках — в корне проекта). Там же появляются резервные копии и файлы, которые создаёт код уроков. Чтобы перенести прогресс на другой компьютер — «Настройки» → «Экспорт прогресса».

## 📚 Про книги и авторские права

В репозиторий намеренно не включён файл `web/books/grokking.pdf` («Грокаем алгоритмы», Aditya Bhargava, Groking Algorithms, Manning Publications): книга защищена авторским правом и распространяться с этим проектом не может. Сейчас код к ней не обращается — теория берётся из `lessons/`, — так что на работу приложения её отсутствие не влияет.

Все материалы уроков (`lessons/`) и иконки (`web/icons/`) — собственные.
